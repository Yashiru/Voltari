# Decision journal

One entry per structuring decision. Code captures the *what*; this journal
captures the *why* — and, above all, the options that were rejected, so a
settled question is not silently reopened six months later.

Format: `NNNN-short-slug.md`, with status, context, decision, rejected options,
consequences. Entries are append-only. A decision that is later reversed gets a
new entry that supersedes the old one; the old entry is marked, never deleted.

Entries 0001 to 0005 were written retroactively on 2026-09-07, covering
decisions taken during the initial specification sessions.
